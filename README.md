# Aplicativo de Agenda Médica

##Sobre o Aplicativo:
Este aplicativo foi desenvolvido como parte de um trabalho acadêmico da disciplina de Programação para Dispositivos Móveis.
O objetivo do projeto é aplicar conceitos de desenvolvimento mobile, interface de usuário, armazenamento de dados e funcionalidades de um aplicativo CRUD, desenvolvido em React Native com Expo para auxiliar pacientes no controle de medicamentos e permitir o acompanhamento por cuidadores.

## Funcionalidades

- Cadastro de medicamentos
- Definição de horário para cada medicamento
- Notificações automáticas no horário configurado
- Edição de medicamentos
- Exclusão de medicamentos
- Sistema de autenticação de usuários
- Integração entre paciente e cuidador
- Sincronização em nuvem utilizando Firebase Firestore

## Tecnologias Utilizadas

- React Native
- Expo
- TypeScript
- Firebase Authentication
- Firebase Firestore
- Expo Notifications
- React Navigation

## Estrutura do Projeto

### Paciente
O paciente pode:

- Cadastrar medicamentos
- Editar medicamentos
- Excluir medicamentos
- Receber notificações de lembrete

### Cuidador
O cuidador pode:

- Cadastrar medicamentos
- Editar medicamentos
- Excluir medicamentos
- Vincular pacientes através do e-mail
- Visualizar medicamentos do paciente
- Acompanhar horários de medicação
